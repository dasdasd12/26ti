# 李萨如图形频偏校正 Python 仿真

这是一个信号级、非 RTL 仿真，用来验证信号源与 FPGA 使用独立晶振时的频偏校正。当前默认方案是直接电气标定，不使用摄像头；原摄像头相位闭环仿真仍保留用于后续比较。

## 直接标定方案（当前默认）

在断开信号源与 FPGA 连接之前，先把信号源设置为已知校准频点，FPGA 在整数个信号源周期内累计本地 12.5 MHz 采样时钟数：

```text
信号源校准频率 ─> AD/过零检测 ─> 累计 Nsrc 个信号周期
                                      │
12.5 MHz 本地采样时钟 ────────────────> 同时累计 Nsample
```

由此得到 FPGA 时钟相对信号源时基的比例：

```text
Fs_effective = Nsample * Fcal_setting / Nsrc
clock_ratio  = Fs_effective / 12.5 MHz
```

后续 DDS 直接使用标定后的有效采样率：

```text
DDS_word = round(Ftarget_setting / Fs_effective * 2^32)
```

这种方法标定的是两个晶振的相对比例。只要校准和测试使用同一台、时基稳定的信号源，信号源自身的绝对频率误差会在比例中抵消。

默认设置是在 100 kHz 校准 5 s，即累计 500,000 个信号周期和约 62,500,000 个采样周期。仿真额外覆盖起止过零检测相差 `-1/0/+1` 个采样时钟的情况。

运行直接标定仿真和测试：

```powershell
& ".\phase sim\run_sim.ps1"
python ".\phase sim\test_direct_calibration_sim.py"
```

直接标定结果写入 `direct_output/`。

本次直接标定扫描结果：

- 100 kHz、2 倍频、FPGA 相对快 `50 ppm`：频偏从 `+10.000768 Hz` 降到 `+0.000192 Hz`；
- 全频段、1 倍频/2 倍频、`±25/±50 ppm`、起止检测 `±1` 个采样时钟，共 `23,784` 个工况；
- 失败 `0` 个，最坏残余频偏 `0.006134 Hz`。

## 实际链路对应关系

赛题自动模式中，信号源只接示波器 X 轴，FPGA 装置只接 Y 轴，两者没有电气耦合。仓库现有设计使用 Mizar Z7 的 50 MHz PL 有源晶振，分频得到 12.5 MHz AD/DA 时钟。因此自动输出可抽象为：

```text
信号源 ───────────────────────────────> 示波器 X
50 MHz FPGA 晶振 -> 12.5 MHz DDS/DA ─> 示波器 Y
                              相机 ──> 李萨如相位观测
                                          │
                                          └─> 频偏估计 -> 修正 DDS 频率字
```

有线直通/正交模式可以直接从 AD 输入跟随信号源，不存在长期独立频偏；本仿真针对题目第 5 项断开电气连接后的自动模式。

## 频偏模型

设 FPGA 晶振相对误差为 `epsilon`，DDS 命令频率为 `f_cmd`，则实际输出近似为：

```text
f_out = round(f_cmd / 12.5 MHz * 2^32) / 2^32
        * 12.5 MHz * (1 + epsilon)
```

目标输出为 `h * f_src`，其中 `h=1` 对应直线/圆，`h=2` 对应“∞”图形。频差为：

```text
delta_f = f_out - h * f_src
```

李萨如相位以 `2*pi*delta_f` rad/s 漂移，因此 1 Hz 频差就是每秒旋转一圈；0.01 Hz 对应 3.6 deg/s。

仿真用 30 fps 相机输出的带噪、带少量离群点的包裹相位，先用相邻帧相位增量得到粗频偏，再用 Huber 鲁棒直线拟合得到精确频偏：

```text
f_cmd,new = f_cmd,old - estimated_delta_f
```

默认用 3 s 完成估计和修正，再观察 5 s 验证稳定性，合计 8 s，分别对应赛题“控制时间不超过 10 s”和“稳定时间至少 5 s”。

## 运行

摄像头方案需要单独执行：

```powershell
& ".\phase sim\run_camera_sim.ps1"
python ".\phase sim\test_frequency_offset_sim.py"
```

单个自定义演示：

```powershell
python ".\phase sim\frequency_offset_sim.py" `
  --source-frequency-hz 50000 `
  --clock-error-ppm -30 `
  --skip-sweep
```

默认完整扫描包括：

- 信号源频率：1 kHz 到 100 kHz，步进 100 Hz；
- 输出模式：1 倍频和 2 倍频；
- FPGA 晶振偏差：-50、-25、+25、+50 ppm；
- 32 位 DDS，相位观测 30 fps；
- 相位噪声 0.5 deg RMS，2% 离群点；
- 通过条件：校正后真实频差和相机复测频差都小于 0.01 Hz。

结果写入 `output/`：

- `summary.json`：演示和全频段汇总；
- `frequency_sweep.csv`：每个扫描点的原始/校正频偏；
- `calibration_demo.png`：100 kHz、+50 ppm 校正前后相位和李萨如图；
- `frequency_sweep.png`：全频段最坏频偏包络。

本次固定随机种子仿真结果：

- 100 kHz、+50 ppm 演示：原始真实频偏 `+4.998929 Hz`，校正后真实频偏 `+0.001551 Hz`，相机复测 `+0.001492 Hz`；
- 全频段共 `7,928` 个工况，失败 `0` 个；
- 全频段最大真实残余频偏 `0.003391 Hz`；
- 全频段最大相机复测残余频偏 `0.003560 Hz`。

## 设计边界

- 30 fps 的包裹相位跟踪要求初始频偏绝对值小于 15 Hz。默认最坏点是 2 倍频、100 kHz、50 ppm，对应 10 Hz，仍可无混叠跟踪。
- 若晶振可能超过约 75 ppm，2 倍频 100 kHz 时应提高相机帧率，或先做粗频率扫描，再进入本仿真的精跟踪环。
- 32 位 DDS 在 12.5 MHz 下的频率分辨率约为 0.00291 Hz，量化误差上限约 0.00146 Hz，满足 0.01 Hz 指标。若直接用 50 MHz 更新 DDS，至少应使用 32 位；更稳妥可用 36 位以上。
- 本模型把图像算法抽象成“李萨如相位测量 + 噪声/离群点”。上机时仍需从相机像素提取椭圆方向或“∞”图形相位，并用实测噪声替换仿真参数。
