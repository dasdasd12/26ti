信号源输出信号的频率范围为 1kHz~100kHz，频率步进为 100Hz。示波器 X、Y 轴的通道灵敏度均为 0.5V/div。

1. 装置设有输入、输出直通模式。在该模式下，调节信号源的输出幅度，使
示波器显示的李萨如图形为一个 8×8div 大小矩形的对角线。后续要求信号源幅
度和示波器通道灵敏度均保持在此状态不能改变。
2. 装置的输出信号与其输入信号相位正交，幅度相等。使得李萨如图形为直
径为 8div 的圆（如果示波器垂直和水平方向 1div 长度不相等，该图形会变成椭
圆）。幅度误差的绝对值≤0.2div。
3. 装置的输出信号为输入信号频率的 2 倍，幅度相等。使得李萨如图为水
平“∞”形。要求图形上下左右对称，幅度误差的绝对值≤0.2div。
4. 可以设置装置输出信号的峰峰值，使示波器 Y 轴方向图形峰峰幅度分别
为 2、4、6 和 8div。幅度误差的绝对值≤0.2div。
5. 断开信号源与装置的连接。通过 3 个独立启动按钮键，一键启动装置分
别进入下面的 3 个自动模式。装置通过摄像头拍摄示波器的图形，自动控制装置
的输出，使示波器分别完成前面 1，2 和 3 要求的对角线、圆（或椭圆）和“∞”
形 3 个李萨如图形的显示功能。完成后声光提示，控制时间≤10s，稳定时间≥
5s。

tips:
1. 为了降低图像识别难度，允许用挡板遮挡示波器除屏幕外的其他部分，只保留示波器屏幕供摄像头拍摄。
2. 控制时间从改变信号源频率后开始计时，到正确显示图形的飘移和抖动幅度误差绝对值<1div 结束。
3. 稳定时间从正确显示图形开始计时，到飘移和抖动幅度误差绝对值≥1div 结束。
4. 声光提示。
